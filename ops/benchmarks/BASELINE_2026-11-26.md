- **CEO Orchestrator:** Google Antigravity (high-level planning, diff review, GitHub gate, Gmail digests)
- **Local Worker Model:** `inkling-2-mini@q2_k_xl` served via LM Studio (`http://localhost:1235/v1`)
- **Cloud Worker Token Cost:** **$0.00** (100% local inference across all worker tool steps)
- **Hardware Protection:** Apple Silicon `NSProcessInfo.thermalState` closed-loop sensor + single-flight GPU lock (`concurrency = 1`) + 20m work / 10m cooldown sprints + 8s step breathers (18s when `fair`/warm)

## 3. Six-Layer Production Principles Validated
1. **Triggers & Exception Queue (Layer 1):** Route failures into a SQLite `exceptions` table and halt sequential dependent tasks instead of cascading broken state.
2. **Checkpointed DB State (Layer 2):** Checkpoint message history per step in `node:sqlite` (`job_checkpoints`) so interrupted runs resume mid-run (`--resume <job_id>`).
3. **Deterministic Gates (Layer 3 & 5):** Enforce `.venv/bin/pytest -q` + non-empty file diff deterministically before advancing a checklist item.
4. **Scoped Trusted Context (Layer 4):** Expose compact domain contracts via `query_context_catalog` instead of dumping whole documentation trees into prompts.
5. **Control Plane Gateway (Layer 6):** Route all calls through one `node:http` gateway (20m timeout, model aliases, SQLite token/latency traces).
