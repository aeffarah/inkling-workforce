# Inkling Local Workforce — Baseline Swarm Benchmark (2026-11-26)

## 1. Environment & Stack
- **CEO Orchestrator:** Google Antigravity (high-level planning, diff review, GitHub gate, Gmail digests)
- **Local Worker Model:** `inkling-2-mini@q2_k_xl` served via LM Studio (`http://localhost:1235/v1`)
- **Cloud Worker Token Cost:** **$0.00** (100% local inference across all worker tool steps)
- **Hardware Protection:** Apple Silicon `NSProcessInfo.thermalState` closed-loop sensor + single-flight GPU lock (`concurrency = 1`) + 20m work / 10m cooldown sprints + 8s step breathers (18s when `fair`/warm)

## 3. Key Operating Rules Validated by Benchmark
1. **Never starve `max_tokens` on thinking models:** Reasoning tokens share the `max_tokens` ceiling in OpenAI-compatible servers. Keep `max_tokens >= 6144` and instruct workers to write **one file per step**.
2. **Control heat via duty-cycle & step breathers, not concurrent workers:** Single-flight GPU locking + 8s/18s step breathers keeps `NSProcessInfo.thermalState` at `nominal (0/3)` without truncating outputs.
3. **Verify file/test artifacts, not just exit codes:** Empty completions now throw/retry automatically rather than advancing the backlog checklist.
